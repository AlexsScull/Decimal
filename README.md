## Особенности

- **Точные вычисления** - исключение ошибок округления характерных для float/double
- **Поддержка больших чисел** - 96-битная мантисса с масштабом от 0 до 28
- **Банковское округление** - корректная обработка граничных случаев
- **Полный набор операций** - арифметика, сравнения, преобразования
- **Кроссплатформенность** - соответствует стандарту C11
- **Автоматическая документация** - генерация документации через Doxygen

## Битовое представление

Тип `s21_decimal` реализован как структура с массивом из четырех 32-битных целых чисел:

```c
typedef struct {
    int bits[4];
} s21_decimal;
```

### Распределение битов:

- **bits[0], bits[1], bits[2]** - младшая, средняя и старшая части 96-битного целого числа
- **bits[3]** - служебное поле:
  - **Биты 0-15** - не используются (0)
  - **Биты 16-23** - масштаб (0-28)
  - **Биты 24-30** - не используются (0)
  - **Бит 31** - знак (0 - положительный, 1 - отрицательный)

## API функции

### Арифметические операторы

```c
int s21_add(s21_decimal value_1, s21_decimal value_2, s21_decimal *result);  //  +
int s21_sub(s21_decimal value_1, s21_decimal value_2, s21_decimal *result);  //  -
int s21_mul(s21_decimal value_1, s21_decimal value_2, s21_decimal *result);  //  *
int s21_div(s21_decimal value_1, s21_decimal value_2, s21_decimal *result);  //  /
```

**Коды возврата:**
- `0` - OK
- `1` - число слишком велико или равно бесконечности
- `2` - число слишком мало или равно отрицательной бесконечности
- `3` - деление на ноль

### Операторы сравнения

```c
int s21_is_less(s21_decimal, s21_decimal);              //  <
int s21_is_less_or_equal(s21_decimal, s21_decimal);     //  <=
int s21_is_greater(s21_decimal, s21_decimal);           //  >
int s21_is_greater_or_equal(s21_decimal, s21_decimal);  //  >=
int s21_is_equal(s21_decimal, s21_decimal);             //  ==
int s21_is_not_equal(s21_decimal, s21_decimal);         //  !=
```

**Коды возврата:**
- `0` - FALSE
- `1` - TRUE

### Преобразователи

```c
int s21_from_int_to_decimal(int src, s21_decimal *dst);         //  Из int
int s21_from_float_to_decimal(float src, s21_decimal *dst);     //  Из float
int s21_from_decimal_to_int(s21_decimal src, int *dst);         //  В int
int s21_from_decimal_to_float(s21_decimal src, float *dst);     //  В float
```

**Коды возврата:**
- `0` - OK
- `1` - ошибка конвертации

### Другие функции

```c
int s21_floor(s21_decimal value, s21_decimal *result);      //  К меньшему
int s21_round(s21_decimal value, s21_decimal *result);      //  Банковское округление
int s21_truncate(s21_decimal value, s21_decimal *result);   //  Отсечение дробной части
int s21_negate(s21_decimal value, s21_decimal *result);     //  Смена знака
```

**Коды возврата:**
- `0` - OK
- `1` - ошибка вычисления

## Документация

Проект включает автоматическую генерацию документации с помощью **Doxygen**. Все функции снабжены комментариями в Doxygen-стиле.

### Генерация документации

```bash
# Через Makefile (из src/ будет сгенерированна в __корневой__ директории)
make docs

# Или вручную через Doxygen (из __корневой__ директории)
doxygen Doxyfile
```
### Просмотр документации

Документация будет сгенерирована в __корневой__ директории в папке `docs/html/`. Откройте `docs/html/index.html` в браузере для просмотра.

### Особенности документации

- **Полное описание API** - все функции с параметрами и возвращаемыми значениями
- **Структура данных** - подробное описание битового представления
- **Примеры использования** - сниппеты кода для основных операций
- **Диаграммы** - визуализация связей между компонентами
- **Поиск** - полнотекстовый поиск по документации

## Тесты

Проект включает следующие тестовые модули:

- **Arithmetic** - тесты арифметических операций
- **Comparison** - тесты операторов сравнения
- **Conversion** - тесты преобразования типов
- **Other** - тесты дополнительных функций
- **Helpers** - тесты вспомогательных функций

### Запуск тестов

Запуск тестов производится с помощью

`make test`

Или с помощью скрипта run_tests.sh:

```bash
# Запуск всех тестов
./run_tests.sh

# Запуск всех тестов с подробным выводом
./run_tests.sh +

# Запуск конкретного теста
./run_tests.sh Arithmetic       # Тест Arithmetic
./run_tests.sh Arithmetic +     # Тест Arithmetic с подробным выводом

# Комбинирование опций
./run_tests.sh Arithmetic Comparison    # Тесты Arithmetic и Comparison
./run_tests.sh Arithmetic Comparison +  # Тесты Arithmetic и Comparison с подробным выводом
```
